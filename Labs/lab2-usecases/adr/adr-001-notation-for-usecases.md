# ADR-001: Нотація для Use Case діаграми

## Контекст

ADR-002 із Lab1 вибрав Mermaid для ER. Але для use case діаграми в Mermaid
немає нативного типу — доведеться або ламати синтаксис, або міняти нотацію.

## Розглянуті альтернативи

1. Mermaid `flowchart` — зображу еліпси як прямокутники, втрачається суть
   нотації. Відкинув.
2. PlantUML `usecase` — повна нотація, є актори, include/extend/generalization.
   Але для рендера потрібен сервер або Java (її в мене немає).
3. Малювати в draw.io — не декларативно.

## Рішення

PlantUML. Рендери роблю через plantuml.com / GitHub action, у репо
класні PNG у `renders/`. Вихідний текст і картинка в одному коміті, як
вимагають правила.

## Наслідки

- ER у Mermaid, use cases у PlantUML — два стилі в одному курсі, це нормально,
  бо в умові прямо перелічено обидві нотації як рівноцінні.
- Потрібен крок «згенерувати картинку» — не автоматизований.
