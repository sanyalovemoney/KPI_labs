## Домен

**Онлайн-бібліотека з підпискою** — книжковий сервіс за моделлю Bookmate.
Користувач оформлює підписку на тариф, читає книги з каталогу, залишає оцінки.

Домен обрано самостійно за категорією підписних книжкових платформ (модель Bookmate): він поєднує чистий M:N і асоціативну сутність для ER, зовнішнього актора для Use Cases / Sequence та наскрізну логіку для всього ланцюга робіт.
Детальне обґрунтування вибору — у [README Завдання 1](Labs/lab1-er/README.md#чому-цей-домен).


## Шлях виконання

Завдання виконуються з використанням AI. Відповідно до вимог курсу
(RULES.md, розділ «Два шляхи»), у кожній роботі додається папка `ai/` зі слідом
промптів і аудитом виходу AI: топ-3 помилки, знайдені й виправлені, з посиланням
на промпт і коміт.
